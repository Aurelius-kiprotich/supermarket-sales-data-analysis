# Supermarket Sales Data Analysis

## Project Overview
This project performs exploratory data analysis (EDA) on a supermarket sales dataset to uncover patterns in customer behavior, product performance, and revenue trends.

The analysis was conducted using Python and focuses on identifying key business insights that can help improve decision-making in retail environments.


## Objectives
- Analyze sales performance across different product lines
- Understand customer purchasing patterns
- Identify peak sales periods
- Visualize trends using charts and graphs


## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook


## Dataset
The dataset contains transaction records from a supermarket including:

- Invoice ID
- Product line
- Customer type
- Gender
- Unit price
- Quantity
- Total sales
- Date and time


## Key Insights
Some findings from the analysis include:

- Certain product lines generate significantly higher revenue
- Sales tend to peak during specific times of the day
- Customer demographics influence purchasing behavior


## Visualizations
The project includes several visualizations such as:

- Sales by product line
- Customer gender distribution
- Total revenue trends over time
